## 一句话理解项目

`SpectralStore` 是一个面向时序图近似查询处理（AQP, Approximate Query Processing）的研究型 Python 系统。它把时序图快照压缩为低秩因子化存储，并在压缩域上执行查询、构建索引、评估存储/精度/延迟之间的系统权衡。

## 当前代码形态

- 这是一个“可导入核心库 + 脚本式实验入口”的研究工程，不是单体 Web 服务。
- `src/spectralstore` 是可复用的核心实现。
- `scripts/` 是实验和数据下载入口，原则上应保持轻量。
- `experiments/configs/` 保存可复现实验配置。
- `docs/` 中的现有文档更偏项目状态、手册与交接；本 Wiki 更偏代码结构与工程理解。
