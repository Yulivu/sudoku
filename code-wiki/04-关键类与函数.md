# 关键类与函数

本页聚焦“真正控制系统行为”的类与函数，适合在修改代码前快速定位。

## 1. 压缩与存储层

### 1.1 `SpectralCompressionConfig`

位置：`src/spectralstore/compression/spectral.py`

用途：

- 统一描述压缩器的超参数与行为开关。
- 同时覆盖 rank、ARD、robust residual thresholding、storage gate、残差格式等多个子机制。

关键字段：

- `rank`: 目标秩
- `rank_selection_mode`: `fixed` 或 `ard`
- `residual_threshold_mode`: `mad` / `quantile` / `hybrid`
- `residual_threshold_scale`: 残差阈值缩放
- `residual_storage_format`: `csr` / `temporal_coo`
- `max_sparse_ratio`: 稀疏残差占比上限
- `storage_gate_action`: 超限后的动作
- `factor_storage_dtype_bytes`: 估算压缩体积时使用的因子字节数

### 1.2 `FactorizedTemporalStore`

位置：`src/spectralstore/compression/factorized_store.py`

职责：

- 统一表示压缩后的时序图。
- 支持查询、误差界、体积统计、持久化。

最关键的方法：

- `link_score(u, v, t, include_residual=True)`
  - 返回边 `(u, v, t)` 的估计值
- `dense_snapshot(t, include_residual=True)`
  - 重建第 `t` 个快照
- `residual_value(t, u, v)`
  - 返回残差层中某个元素的值
- `residual_row(t, u)`
  - 返回某一行残差，用于 Q2 residual rerank
- `entrywise_error_bound(...)`
  - 返回某个条目的理论或经验误差界
- `compressed_bytes(...)`
  - 返回压缩后总字节数
- `save_npz(path)` / `load_npz(path)`
  - 持久化与恢复 store

### 1.3 `TemporalCOOResidualStore`

位置：`src/spectralstore/compression/factorized_store.py`

职责：

- 以统一的时序 COO 形式存储残差。

关键方法：

- `from_csr_residuals()`
- `value()`
- `row()`
- `snapshot()`

适用场景：

- 统一管理多时间片残差
- 为持久化与跨时间访问提供更一致的数据布局

### 1.4 `UnifiedThinkingSpectralCompressor`

位置：`src/spectralstore/compression/spectral.py`

职责：

- 当前项目主压缩器实现。

关键方法：

- `fit_transform(snapshots)`

特点：

- 把 Thinking 方案中的 mode-3 结构、ARD、robust residual 分离和误差界元数据写入整合在一起。

### 1.5 压缩器创建入口

位置：`src/spectralstore/compression/registry.py`

关键函数：

- `create_compressor(name, config)`
  - 按名称创建压缩器实例
- `spectral_config_from_mapping(values, **overrides)`
  - 从字典配置中构造 `SpectralCompressionConfig`
- `available_compressors()`
  - 返回支持的方法名列表

常见方法名：

- `spectralstore_thinking`
- `sym_svd`
- `direct_svd`
- `rpca_svd`
- `tensor_unfolding_svd`
- `cp_als`
- `tucker_hosvd`
- `nmf`

## 3. 索引层

### 3.1 `ExactMIPSIndex`

位置：`src/spectralstore/index/exact_mips.py`

职责：

- 对 target embedding 做精确内积检索。

关键方法：

- `from_store()`
- `search()`
- `save_npz()` / `load_npz()`

特点：

- 简单、稳定、便于作为基准索引路径

### 3.2 `MaterializedTopKIndex`

位置：`src/spectralstore/index/materialized_topk.py`

职责：

- 为每个 `(t, source)` 预计算 factor-only top-L 邻居。

关键方法：

- `from_store()`
- `search()`
- `save_npz()` / `load_npz()`

使用场景：

- 背景语义查询
- 低延迟、可复用的 Q2 factor-only path

### 3.3 `RandomProjectionANNMIPSIndex`

位置：`src/spectralstore/index/ann_mips.py`

职责：

- 使用随机投影做 ANN 候选筛选，再用精确分数排序。

关键方法：

- `from_store()`
- `search()`
- `save_npz()` / `load_npz()`

关键字段：

- `projection_matrix`
- `projected_right_embeddings`
- `candidate_multiplier`

### 3.4 `ProductQuantizedMIPSIndex`

位置：`src/spectralstore/index/pq_mips.py`

职责：

- 提供 PQ-MIPS 原型实现。

适用定位：

- 系统实验原型
- 不是工业级高性能实现

### 3.5 `IVFProductQuantizedMIPSIndex`

位置：`src/spectralstore/index/ivfpq_mips.py`

职责：

- 提供 IVF-PQ 原型实现，用于更接近真实 ANN 系统的路径比较。

### 3.6 `ExternalANNMIPSIndex`

位置：`src/spectralstore/index/external_ann_mips.py`

职责：

- 适配外部 ANN 库并提供统一接口。

支持后端：

- `faiss_flat_ip`
- `faiss_ivfpq`
- `hnswlib_ip`
- `numpy`
- `auto`

关键方法：

- `from_store()`
- `available_backends()`
- `search()`
- `candidate_search()`
- `batch_search()`
- `save_npz()` / `load_npz()`

### 3.7 `CommunityInvertedIndex`

位置：`src/spectralstore/index/community.py`

职责：

- 按 `(time, community)` 组织 posting list。

关键方法：

- `from_labels()`
- `labels()`
- `node_community()`
- `nodes_for()`
- `nodes()`
- `save_npz()` / `load_npz()`

### 3.8 `TemporalBPlusTree` 与 `TemporalTrendIndex`

位置：`src/spectralstore/index/temporal.py`

职责：

- `TemporalBPlusTree`: 提供紧凑的时间范围扫描结构
- `TemporalTrendIndex`: 在其上封装 Q4 趋势查询

关键方法：

- `TemporalBPlusTree.build()`
- `TemporalBPlusTree.range_values()`
- `TemporalTrendIndex.from_store()`
- `TemporalTrendIndex.trend()`
- `TemporalTrendIndex.save_npz()` / `load_npz()`
